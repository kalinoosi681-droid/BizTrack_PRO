# Quick Email Setup Guide

## 30-Second Setup for Gmail

### Step 1: Get Your App Password
1. Go to https://myaccount.google.com/apppasswords
2. Select "Mail" and "Windows Computer"
3. Copy the 16-character password

### Step 2: Create .env File
```bash
# Copy template
cp .env.example .env

# Edit .env and add:
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-16-char-app-password
MAIL_DEFAULT_SENDER=your-email@gmail.com
```

### Step 3: Install & Run
```bash
pip install Flask-Mail
python run.py
```

### Step 4: Test
- Go to any invoice
- Click "Send via Email"
- Enter test email
- Done! ✅

## Troubleshooting

**"Email not configured" error**
→ Check `.env` file exists and MAIL_USERNAME is set

**Gmail says "App password not allowed"**
→ Enable 2FA on Gmail account first, then generate app password

**SMTP connection error**
→ Verify email/password correct, check firewall allows port 587

**Button not working**
→ Check browser console (F12) for JavaScript errors

## Email Providers

Choose one:

| Provider | Server | Port | TLS | Username | Password |
|----------|--------|------|-----|----------|----------|
| **Gmail** | smtp.gmail.com | 587 | ✓ | your@gmail.com | App password |
| **SendGrid** | smtp.sendgrid.net | 587 | ✓ | apikey | API key |
| **Office365** | smtp.office365.com | 587 | ✓ | you@outlook.com | Password |

## For Production

1. Use SendGrid or similar service (not Gmail)
2. Store credentials in server environment, not `.env`
3. Consider async email with Celery for scale
4. Set up email bouncing/delivery tracking
